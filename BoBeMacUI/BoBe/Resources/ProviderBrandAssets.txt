Provider artwork
================

These marks identify model providers. They do not imply endorsement of BoBe.
All trademarks remain the property of their respective owners. No asset is
loaded from the network at runtime. The custom/local endpoint keeps a generic
system icon because it has no provider brand.

Sources retrieved 2026-10-07 (UTC):

OpenAI
https://github.com/openai/openai-assistants-quickstart/blob/main/public/openai.svg
Official OpenAI repository; source blob 98d4eddc88e4982da8f58cd0bf8af321c27e93e3.
The vector geometry is unchanged. Its monochrome mask renders black or white.
The repository's MIT notice is reproduced below.

Anthropic
https://www.anthropic.com/news -> https://anthropic.com/press-kit
https://www-cdn.anthropic.com/ae59ca4ca194dac9c9dc3bc78c5829468cb0e8af.zip
Anthropic media resources / Anthropic logos / Anthropic logos /
2 Anthropic symbol / SVG / Anthropic symbol - Slate.svg and
Anthropic symbol - Ivory.svg. Both supplied variants are unchanged.
Vendor media assets, not covered by the MIT notices below.

DeepSeek
https://github.com/deepseek-ai/DeepSeek-V2/blob/main/figures/logo.svg
The company's DeepSeek-V3 README also links to this logo. The whale path is
unchanged; the wordmark is omitted and the view box fits the standalone symbol.
The supplied #4D6BFE color is retained. Repository MIT notice below.

OpenRouter
https://openrouter.ai/brand
https://openrouter.ai/brand/logos/transparent/glyph/svg/glyph-grape.svg
https://openrouter.ai/brand/logos/transparent/glyph/svg/glyph-volt.svg
Official glyphs for light and dark surfaces, unchanged. The brand page asks
users not to stretch, recolor, or remix the marks. They render in original color.
Vendor brand assets, not covered by the MIT notices below.

GitHub Copilot
https://github.com/primer/octicons/blob/main/icons/copilot-24.svg
Official GitHub Octicons; source blob 201ecf408786f8e248ed4a223262c11c6eb726c0.
The vector geometry is unchanged. Its monochrome mask renders black or white.
Octicons MIT notice below.

Rail Relay
Owner-provided RailRelay2 repository:
web/packages/ui/src/components/logo-mark.tsx
web/packages/ui/src/design.css
The logo geometry is unchanged. JSX attributes are serialized as SVG attributes.
The source's light/dark --rr-accent values (#d7801f / #e9953a) are resolved into
the bundled variants. This is Rail Relay's own mark, not Noiplex's earlier icon.
