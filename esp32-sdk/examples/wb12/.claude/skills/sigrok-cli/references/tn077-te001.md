# TN077 / TE001 reference

This optional target reference describes a TN077/TE001 analyzer observed on macOS.
It is not part of the generic sigrok command contract.

## Observed identity

| Field | Value |
|---|---|
| Label | TN077 |
| Model | TE001 |
| Marking | Yuan Technology Ltd. |
| USB VID:PID | `0925:3881` |
| Pre-firmware `bcdDevice` | `0001` |
| USB speed | High-speed |
| Channels | 8 |
| Advertised maximum | 24 MS/s |
| libsigrok profile | `saleae-logic` through `fx2lafw` |

There are no manufacturer/product/serial USB strings. Identity therefore
depends on exact VID/PID, pre-firmware revision, high-speed operation, physical
location, unique enumeration and a measured lead-to-channel map.

Run `tools/sigrok.sh discover --vid 0925 --pid 3881` and set `ANALYZER_LOCATION`
to the selected analyzer's current IOKit location. Location and libusb connection
values depend on the host and USB connection.

Read-only check:

```bash
tools/sigrok.sh doctor \
  --vid 0925 \
  --pid 3881 \
  --location "$ANALYZER_LOCATION" \
  --expected-bcd 0001 \
  --expected-state original
```

## Limits

The enclosure's `24 MHz` marking is treated as a 24 MS/s cap. It is suitable
for buttons, reset, UART, I2C, typical I2S and modest SPI. It is not a credible
analyzer for a 40 MHz or 80 MHz display bus.

The input circuit and protection rating are unverified. Use only 0-3.3 V logic
until the PCB or a trustworthy manual establishes more; see the
[electrical boundary](electrical.md).

## Firmware transition

The approved firmware is `fx2lafw-saleae-logic.fw`, SHA-256:

```text
79858c9ca73e82d8e3d9b749d4ef73b5a4c2cc18713056987cb19881e39c34f0
```

The first firmware probe must be performed with signal leads disconnected. It
is volatile RAM upload; unplugging restores the original state.

```bash
tools/sigrok.sh probe \
  --vid 0925 \
  --pid 3881 \
  --location "$ANALYZER_LOCATION" \
  --expected-bcd 0001 \
  --expected-state original
```

On this observed unit, loaded `fx2lafw` retains `bcdDevice 0001` and changes the
USB strings to manufacturer `sigrok`, product `fx2lafw`, serial
`Saleae Logic`. Immediate capture uses `--expected-bcd 0001` with
`--expected-state fx2lafw`. After a power cycle it uses `--expected-bcd 0001` with
`--expected-state original` and uploads firmware again.

Before using captures as evidence, qualify:

1. every lead's physical mapping to `D0`-`D7`;
2. idle low/high interpretation with a current-limited 3.3 V source;
3. sustained 1, 6, 12 and 24 MS/s capture against a known waveform;
4. sample integrity and drop behavior at each rate.

Until qualification is retained, captures are development diagnostics rather
than calibrated timing evidence.
